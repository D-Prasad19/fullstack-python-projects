# 🕒 Analog Clock  

A sleek **Analog Clock** built with **HTML, CSS, and JavaScript**.  
The clock updates in real time with smoothly rotating hour, minute, and second hands.  

---

## 🌟 Features
- ⏰ Real-time working analog clock.  
- 🎨 Stylish dark theme with colored clock hands.  
- 📱 Responsive and centered layout.  
- ⚡ Lightweight and runs in any modern browser.  

---

## 🛠️ Technologies
- **HTML5** → Clock structure and layout.  
- **CSS3** → Styling for clock face, numbers, and hands.  
- **JavaScript (ES6)** → Real-time updates for hands movement.
