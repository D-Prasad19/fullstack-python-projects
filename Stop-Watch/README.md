# ⏱ Stopwatch (HTML, CSS, JavaScript)

A simple and responsive **Stopwatch** built with HTML, CSS, and JavaScript.  
Includes **Start, Pause, and Reset** functionality with a clean UI.

---

## 🚀 Features
- Start, Pause, Reset functionality
- Real-time display in **HH:MM:SS** format
- Clean dark theme UI
- Lightweight and responsive
