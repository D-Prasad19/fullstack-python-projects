# ​ Digital Clock

A modern **Digital Clock** built with **HTML, CSS, and JavaScript**, displaying hours, minutes, and seconds in real time with a stylish and responsive design.

---

##  Features
- ⏱ Real-time, ticking digital clock.
-  Clean, minimalist design with customizable colors.
-  Fully responsive and centered layout.
-  Lightweight and runs smoothly in any modern web browser.

---

##  Technologies
- **HTML5** → Structure and layout of the clock.
- **CSS3** → Styling for digital look and responsiveness.
- **JavaScript (ES6)** → Continuously updates the clock every second.
